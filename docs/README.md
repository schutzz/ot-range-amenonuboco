# docs/

公開ドキュメントの置き場です。

設計判断の根拠（決定事項ログ）・時系列の実録（罠ログ）といった内部文書は、リポジトリ外の非公開ワークスペースで管理し、ここには読者向けに整理したドキュメントのみを置きます（前身 `ot-ids-verum` のドキュメント運用を踏襲）。

## ドキュメント一覧

- **[gui-guide.md](./gui-guide.md)** — マニフェストエディタの使い方。ブラウザで開くだけで使えるGUIエディタで、マニフェストを組み立てて書き出すまでの手順（作る順序と依存関係、画面の見方、書き出したYAMLから環境を立ち上げるコマンド、つまずきやすい点）。
- **[manifest-schema-guide.md](./manifest-schema-guide.md)** — マニフェスト記法ガイド（α版 / DRAFT）。サイバーレンジマニフェストを「どう書くか」の記法リファレンス。5層（トポロジ/計装/構造化/検知/攻撃）の書き方、語彙、完全な例を収録。Phase 1 の実装を通じて更新していく。
- **[showcase/](./showcase/)** — 実演のウォークスルー集。マニフェスト→環境生成→攻撃→検知→構造化までを、実データ（実際に観測されたログ・Elasticsearchの中身）で一気通貫に示す記録と、「どこまでがAmenonubocoの自動生成で、どこからがシナリオ側の持ち込みか」を示す境界対応表を、実演ごとに1本のドキュメントとしてまとめる。

Phase が進むにつれて、プロビジョナの使い方、リファレンス実装（`ot-ids-verum` 相当環境）の再現手順などを追加していきます。
