# platform/

マニフェストを読み取り、そこから実際のサイバーレンジ環境を生成するプロビジョナ本体の置き場です。

## 想定する責務

- マニフェスト（`manifests/`）のパースとバリデーション
- トポロジ層 → Docker networks / containers / ルーティングの生成
- 計装層 → ミラーリング/タップ設定の生成（前身 `ot-ids-verum` の `setup_mirror.sh` 相当を、非対称性・冪等化漏れを構造的に防ぐ形で自動生成）
- 構造化層 → tshark ベースの dissect パイプラインの配線（`ot-logs-<protocol>-*` 命名規則の自動適用）
- 検知・攻撃層 → シナリオ側のロジック/スクリプトを載せる差し込み口の提供

## 設計原則

プラットフォームは「構造化まで」の共通基盤に徹します。「何を異常とするか」という検知ロジックは持たず、各シナリオ側の責務とします（前身以来の「既存ツールに任せ、自作は組織固有ポリシーのみ」という方針の、プラットフォームレベルへの拡張）。

実装は Phase 1（トポロジ層の最小プロビジョナ）から着手します。
